# Tamagotchis-ai

https://mxgn0.github.io/Tamagotchis-ai

## Aktueller Stand

- Beim ersten Öffnen schlüpft ein Ei im 3D-Fenster.
- Danach erscheint zufällig eines von fünf Element-Gotchis: **Feuer, Wasser, Erde, Luft, Metall**.
- Das gewählte Element wird im Browser gespeichert und beim nächsten Öffnen wiederverwendet.
- Modell/Element kann zusätzlich jederzeit manuell über die Auswahl im UI gesetzt oder zufällig neu gewürfelt werden.
